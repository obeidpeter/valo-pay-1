# Task help and glossary evidence

Baseline inspected: `83eda41` (PR #78). This is source inspection plus local engineering verification, not participant research. The new help content is release-maintained static guidance; it never reads an organisation, lender, record, role or credential.

| HELP-01 | P1 · Any role understanding a consequential result | At the baseline, `App.tsx` had no `/help` route; `rg --files` found no public help page or searchable task glossary. | HELP-03 | P2 · Returning to a task or finding a term | No central guide deep link, glossary search or search-result return path existed. | Recognition; consistency; user control. | HELP-04 | P2 · Access and failure recovery | Sign-in/invitation and Operations already explained recovery locally, but these explanations could not be searched from a public starting point. | Error recovery; match to real-world tasks. A real app sign-up → Help → return round trip preserves `/sign-up` without an API call. |

## Content checked against implementation

- `src/lib/permissions.ts`: import/run-close/reconciliation roles and Admin/Finance allocation limits; return/refund/reversal holds.
- `src/pages/team-invite.tsx`, `src/lib/workspace-context.tsx`: invitation acceptance recovery, account/lender scope and workspace access boundaries.
- `src/pages/mandates.tsx`, `src/pages/policies.tsx` and their domain controls: suspension, resumption, cancellation/reissue, policy/template preparation and separate approval/application checks.
- `src/features/imports/*`, `lib/valopay-schema/src/import-mapping.ts`: actual Payment evidence label, Use sample, Save and check batch, Commit checked batch, stable row identities and amount units. The help uses the actual interface wording.
- `src/pages/case.tsx`, `src/pages/close-review.tsx`, `src/pages/exports.tsx`: assignee authority, named independent Finance reviewer, current approved snapshots and existing export-job recovery.
- `src/pages/pay-by-bank.tsx`, `src/lib/connected.ts`: sample connected flows and unknown-outcome recovery.
- `src/pages/credit-desk.tsx`, `src/features/credit-desk/*`, `artifacts/api-server/src/domain/connected-credit-service.ts`: separate read/assessment permissions, assessor/reviewer roles, versioned evidence and simulated review.
- `src/pages/cash-desk.tsx`, `src/features/cash-desk/*`: timestamps and unavailable evidence, maker/Finance review, accounting export without posting, VAT preparation without filing, payroll export without execution.
- `src/pages/connections.tsx`: grant/revoke roles, purpose-specific permissions, preserved historical evidence and continued reconciliation of in-flight receipts.
